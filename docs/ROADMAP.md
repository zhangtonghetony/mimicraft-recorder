# Roadmap

## 0.3.2 public preview

The current application covers 29 functional groups: local recording, camera/scene composition, annotations, simple editing, media export, recovery and optional network streaming.

Recent fixes added a camera guide and visible capture-range reset; stopped old crop settings from surviving a restart; enlarged the magnifier; synchronized effect switches; and added regional screenshot stamps with dragging and history.

## Next priorities

1. Wider Windows/display/GPU/device validation and longer recording sessions.
2. Human speech and denoising listening tests, including different microphones.
3. Clearer recording feedback and faster loading of large media lists.
4. Export progress, more keyboard/navigation polish and accessibility.
5. Public build/release reproducibility, signing and installer evaluation.

There are no promised delivery dates. Cloud accounts, a hosted streaming platform and a full multi-track editor are outside the present product scope. All currently planned recorder features remain free.
