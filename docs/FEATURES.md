# 功能清单

0.3.2 的 29 组功能均有可操作实现。这里列的是当前范围，不代表所有硬件、参数组合和异常情况都已完成验收。

| # | 功能 | 当前范围 |
| --- | --- | --- |
| 01 | 基础录制 | 显示器/窗口、预览、开始/停止、H.264 MP4/MKV |
| 02 | 区域录制 | 框选/精确像素、录制中移动、停止后恢复整屏；选区不跨重启保存 |
| 03 | 声音来源 | 不录声/系统声/麦克风/双路、设备与独立增益 |
| 04 | 视频参数 | 720p/1080p、15/20/24/25/30/60fps、码率、饱和度、编码规格与软硬件选择 |
| 05 | 纯音频 | WAV/M4A/MP3、44.1/48kHz、64/128/192/256kbps；纯音频不抓屏 |
| 06 | 文件列表 | 播放、定位、改名、回收站删除、诊断入口 |
| 07 | 快捷控制 | 可移动控制条、开始/暂停/停止/批注、收起/恢复 |
| 08 | 屏幕批注 | 笔/荧光/线/箭头/矩形/圆/文字、橡皮、移动、撤销重做 |
| 09 | 讲解辅助 | 横竖工具条、聚光、360×360物理像素的2倍放大镜、时钟、区域截图贴图 |
| 10 | 画面标记 | 图片/文字、位置/缩放/透明度，支持JPG/JPEG/PNG |
| 11 | 摄像头 | 自动设备列表、三步引导、角落/大小、真实预览、画中画和监看小窗 |
| 12 | 多层场景 | 摄像头/第二来源/图片/文字、排序/显隐/透明度、叠加/分屏、本地预设；最多8层 |
| 13 | 时间安排 | 开始倒数、一次性预约、自动停止和取消；预约需应用保持运行 |
| 14 | 输入提示 | 左右键颜色标记、组合键/功能键显示、全局快捷键和冲突提示 |
| 15 | 声音处理 | 麦克风高通/增益、软噪声门、FFT降噪；听感仍需设备实测 |
| 16 | 单素材整理 | 时间裁剪、分割/删除、历史、缩放、重置与画面裁剪 |
| 17 | 合并 | 多文件/片段排序，统一尺寸、帧率和音轨后导出 |
| 18 | 变速 | 0.25～4倍，画面与声音同步处理 |
| 19 | 转码 | MP4/MKV、360p/720p/1080p、码率；另存、取消、失败提示 |
| 20 | GIF | 时间段、尺寸、帧率、调色板与循环；内置视频播放器不预览GIF动画 |
| 21 | 恢复 | 扫描未完成材料、重封装/时间戳恢复、另存和完整解码检查 |
| 22 | 批量标记 | 图片/文字、逐项导出、坏输入隔离；当前统一720p MP4 |
| 23 | 网络存盘 | HTTP(S)/RTMP(S)/RTSP/UDP/TCP媒体流；停止与超时处理 |
| 24 | 桌面推流 | 场景和声音实时发送，可同时保存本地；UDP本地/局域网 |
| 25 | 文件推流 | 视频列表、排序、格式统一、循环、停止 |
| 26 | 多目的端 | 最多3路，失败隔离；网络接入延迟可能使接收端缺少开头 |
| 27 | 配置与诊断 | 音视频/摄像头/布局/快捷键/目录、日志；不保存推流密钥、临时选区或预约 |
| 28 | 会话控制 | 暂停/继续、倒数取消、托盘和后台继续、关闭保护 |
| 29 | 故障处理 | 临时封装、周期磁盘检查、设备/编码故障提示、RF64音频恢复副本 |

所有当前功能免费，技术上限不对应任何付费套餐。详细测试与剩余边界见[TESTING.md](TESTING.md)。
